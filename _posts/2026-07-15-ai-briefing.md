## 논문

### 1. WARP — 모델 가중치에서 학습 데이터 배합을 복원

**사실:** WARP는 기본 모델과 미세조정 모델 사이를 병합해 가짜 중간 체크포인트를 만들고, 가중치 공간의 기하학적 흔적으로 학습 도메인 비율을 추정합니다. **근거 수치:** 통제 실험에서 BERT의 평균 절대 오차는 **0.046**, GPT-2는 **0.104**였고, 실제 학습 궤적을 쓰는 비교 변형보다도 높은 정확도를 냈습니다. **시사점:** 모델 공급자가 데이터 조성을 공개하지 않아도 오염·편향·능력 드리프트를 외부에서 점검할 수 있어, 오픈 가중치 모델의 실사 기준이 모델 카드에서 가중치 포렌식으로 넓어질 수 있습니다.
→ 원문: [WARP 논문](https://arxiv.org/abs/2607.01686)
→ 교차확인: [Hugging Face 논문 페이지](https://huggingface.co/papers/2607.01686)

### 2. LingBot-World 2.0 — 720p 60프레임의 지속형 상호작용 세계

**사실:** LingBot-World 2.0은 인과 사전학습으로 상호작용 길이 제한을 없애고, 조종 에이전트와 연출 에이전트를 결합해 행동과 환경 생성을 분리했습니다. **근거 수치:** 주 모델은 **140억 매개변수**, 경량 모델은 **13억 매개변수**이며, 실시간 변형은 **720p·60프레임**을 목표로 하고 단일 그래픽처리장치 배포도 지원합니다. **시사점:** 게임 제작에서는 완성 영상을 뽑는 도구보다 플레이어 입력을 계속 받아 세계를 갱신하는 생성형 런타임이 더 직접적인 사업 기회가 되며, 짧은 미니게임 프로토타입으로 검증하기 좋습니다.
→ 원문: [Infinite Worlds with Versatile Interactions](https://arxiv.org/abs/2607.07534)
→ 교차확인: [Hugging Face 트렌딩 논문](https://huggingface.co/papers/2607.07534)

### 3. SkillOpt — 에이전트 스킬을 배포 전 학습 가능한 외부 상태로 전환

**사실:** SkillOpt는 고정된 에이전트가 사용하는 스킬 문서를 별도 최적화 모델이 추가·삭제·교체하고, 검증 점수가 실제로 개선될 때만 편집을 채택합니다. **근거 수치:** **6개 벤치마크·7개 모델·3개 실행 환경의 52개 조합**에서 모두 최고 또는 공동 최고였고, GPT-5.5의 무스킬 대비 정확도를 직접 대화 **23.5점**, Codex 루프 **24.8점**, Claude Code **19.1점** 높였습니다. **시사점:** 프롬프트를 한 번 잘 쓰는 것보다 평가 데이터와 승인 규칙을 갖춘 스킬 개선 루프가 재사용 자산이 되며, 배포 시 추가 추론 호출이 없다는 점도 비용 통제에 유리합니다.
→ 원문: [SkillOpt 논문](https://arxiv.org/abs/2605.23904)
→ 교차확인: [Hugging Face 트렌딩 논문 목록](https://huggingface.co/papers/trending)

### 오늘의 핵심 트렌드 3가지

1. **모델 투명성의 최소 단위가 문서에서 가중치로 내려갔습니다.** WARP가 보여준 것은 공개 설명이 부족해도 학습 배합을 기술적으로 추정할 수 있다는 점입니다. 앞으로 모델 실사는 제공자가 써 준 카드와 독립 분석 결과를 함께 보는 방향으로 바뀔 가능성이 큽니다.
2. **생성 인공지능의 승부처가 결과 한 장에서 지속 가능한 실행면으로 옮겨갑니다.** 60프레임 월드 모델, 브라우저 확장 생성, Creative Agent는 모두 사용자의 다음 행동을 계속 받아 처리하는 제품입니다. 단발 생성 품질보다 편집·상태·배포를 이어주는 제품이 더 오래 남습니다.
3. **프런티어 규제는 원칙 토론보다 심사권의 설계 경쟁이 됐습니다.** 업계 재원, 정부 책임, 국제 모델 적용이라는 구체 조건이 등장했습니다. 누가 평가 기준을 만들고 배포를 늦출 권한을 갖느냐가 다음 산업 구조를 결정할 수 있습니다.

### Jay에게 추천

- **즉시 실행:** LingBot-World 2.0의 공개 코드와 13억 경량 모델을 기준으로, Telegram Mini App 또는 Godot에서 30초짜리 조작 가능 장면 한 개를 기술 검증하십시오. 성공 기준은 영상 품질이 아니라 입력 반응성, 세션 유지 비용, 한 기기에서의 안정 프레임입니다.
