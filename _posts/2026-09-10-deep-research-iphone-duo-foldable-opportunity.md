## Executive Summary

애플이 9월 9일 이벤트 마지막에 "원 모어 띵"으로 첫 폴더블 아이폰 **듀오(iPhone Duo)** 를 공개했다. $1,999(한국 329만원)부터 시작하는 7.6인치 폴더블로, 한국이 1차 출시국에 포함되어 10월 16일 예약·23일 출시된다. 폴더블 시장은 2019년 이후 7년간 글로벌 점유율 1.6%에 머무르며 정체됐지만, 애플 진입을 계기로 2026년 시장이 21~30% 성장하고 애플이 1년차에 25% 점유를 잡을 것이란 전망(Couterpoint/IDC)이 나온다. 진짜 승부처는 하드웨어가 아니라 **√2 종이 비율 설계 + iOS 27의 foldState API**로 대표되는 소프트웨어·앱 생태계 재설계다. iOS 개발자와 인디 게임 개발자에게는 6~12개월 뒤 열리는 '적응형 레이아웃 황금기'를 준비할 시점이다.

## 1. 배경: 폴더블은 왜 7년간 실패했는가

갤럭시 폴드가 2019년 문을 연 뒤 폴더블은 매년 "대중화 원년"이라는 예측을 받았지만 현실는 달랐다.

- **물량의 벽**: IDC 집계 기준 글로벌 폴더블 출하량은 2023년 1,810만 대, 2025년 2,060만 대에 그쳤다. 7년 누적으로도 스마트폰 시장의 **1.6%** 다.
- **성장 정체**: Counterpoint는 2024년 3분기 폴더블 디스플레이 출하가 사상 처음으로 전년 동비 감소했다고 기록했고, DSCC도 2024~2025년 시장이 정체(-4%)에 빠질 것으로 봤다.
- **실패 원인은 명확했다**: ① $1,800+ 가격 ② 무게·두께 ③ 내구성 불안(히지·주름) ④ 그리고 가장 치명적인 것 — **접혔을 때 뭘 할 수 있는지 몰랐던 앱 생태계**. 구글조차 폴더블 최적화 앱이 드물어 안드로이드 17에 이르러서야 '폴더블 게임 모드(상단 게임+하단 가상 컨트롤러)'를 시스템 차원에서 실험 중이다.

즉 폴더블의 문제는 '기술'이 아니라 '경제성과 소프트웨어'였다. 그리고 이 지점이 정확히 애플의 주 특기 분야다.

## 2. 무엇이 달라졌나: iPhone Duo의 설계 철학

### 2.1 하드웨어: 2007년 이후 첫 비(非)평면 아이폰

애플 뉴스룸 원문과 국내 보도를 종합하면 핵심은 이렇다.

| 항목 | 내용 |
|---|---|
| 외형 | 닫으면 5.4인치(아이폰 18 프로 대비 화면 면적 90%), 펼치면 7.6인치(18 프로 맥스 대비 50% 큼) |
| 비율 | 접힌/펼친 화면이 **동일 종횡비(약 1.4:1, √2)** — ISO 216 A시리즈 종이처럼 콘텐츠 비율이 보존됨 |
| 주름 대응 | 나노텍스처 표면으로 반사·주름 시인성 최소화, 내부 FaceTime 카메라는 화면 아래 숨김 |
| 성능 | A20 Pro + 베이퍼챔버 + 듀얼 배터리, 자체 모뎀 C2 |
| 생체인증 | **Face ID 없음 → Touch ID 탑재** (흥미로운 트레이드오프) |
| 입력 | 올해 말 Apple Pencil(USB-C) 지원 — 아이패드 전용이던 펜슬이 아이폰에 처음 |
| 가격 | $1,999(256GB)~2TB까지 4단계, 한국 329만원부터. 케이스 $79, 킥스탠드 폴리오 $129 |

해커뉴스(497포인트, 1,100댓글)에서 가장 뜨거운 논쟁도 바로 이 √2 비율이었다. "종이 규격의 이점이 휴대폰에 무슨 의미냐"는 비판과 "앱이 폼팩터 전환 시 레이아웃 파괴 없이 비율 보존 스케일이 된다는 게 핵심"이라는 옹호가 맞섰다. 결론적으로 이 비율 설계는 **앱 이전(continuity)** 을 시스템 차원에서 보장하겠다는 애플의 선언이다.

### 2.2 소프트웨어: iOS 27의 재설계

iOS 27은 듀오를 위해 홈 화면 구조 자체를 바꿨다. 열면 **좌측에 위젯 세로 스크롤(Today View) + 우측에 앱 2페이지** 구성, 잠금화면 컨트롤·독·내비게이션은 화면 측면으로 이동해 콘텐츠 수직 공간을 극대화했다. 상태바는 원형으로 코너에 안착하고, 다이내믹 아일랜드는 세로로 세워진다. 콘텐츠는 접힘 각도에 반응하고, 뒤집으면 적절한 디스플레이로 자동 전환된다.

개발자에게 중요한 것은 iOS 27에 노출되는 **폴더블 API 계열**이다. iOS 27 베타에서 `foldState`(flat/halfFolded/closed), `angleDegrees`(0~180도 실시간 힌지 각도), 듀얼 배터리 문자열이 확인됐고, 애플은 테크토크 "Prepare your app for iPhone Duo"에서 전체화면 옵트인·유연한 레이아웃 채택을 안내한다. 커뮤니티 가이드가 정리한 개발 패러다임의 전환은 이렇다.

- 사이즈 클래스(compact/regular)만으로는 부족하다 — **자세(posture) 기반 레이아웃**: 평상(flat)·테이블탑(90도 접힘)·북(세로 반접힘) 상태를 별도 UI로 설계
- 힌지 폐색 영역(occlusion rect)에 버튼·텍스트·재생 컨트롤을 두지 않는 레이아웃
- `UIRequiresFullscreen` 플래그로 창 크기 조절을 막는 앱은 **즉시 레터박싱 또는 심사 리젝** 사항이 될 수 있다는 경고
- 외부→내부 디스플레이 전환 시 순간적인 bounds 변화를 견디는 뷰 계층 구조

참고로 이 API 명세는 아직 커뮤니티 문서가 예측을 섞은 상태지만, 방향성 자체는 WWDC 2026의 "적응형 레이아웃으로 가라"는 메시지와 일치한다.

## 3. 시장 시나리오 분석 (Best/Base/Worst)

### 시장 전망의 뼈대

- **Counterpoint(2026.7)**: 2026년 폴더블 시장 +21% 성장, 애플이 **진입 1년차 점유 25%** (삼성 32%, 화웨이 24%)
- **IDC**: 2026년 폴더블 +30%, 전체 스마트폰 시장은 -13.9%(메모리 위기·지정학) — 역설적으로 폴더블은 고가 프리미엄이라 **시장 '가치'는 +3.8%** 증가
- **밍치궈(郭明錤)**: 2026년 하반기 듀오 조립 출하 **700~800만 대**, 즉시 품절·4~6주 배송 지연·리셀 프리미엄 50~100% 예상. 단 생산 난이도 때문에 2027년까지 공급 제약 지속 가능성

### Base Case (확률 ~55%): "프리미엄 니치의 성공적 정착"

700~800만 대 판매, 프리미연 폴더블 시장 재편. 애플 마크로 효과로 폴더블 인지도 상승 → 삼성 Z8도 동반 수혜. 앱 생태계는 2027년에야 본격 최적화. 폴더블이 전체 시장의 10%를 넘는 건 2029년 이후.

### Best Case (~25%): "아이패드 2010 리플레이"

1년차 매출 훨손 + 2세대(2027)에서 가격 인하($1,499급) 시 대중화 가속. 개발자들이 듀오 전용 UX를 만들기 시작하면 폴드폰이 '작은 아이패드+콘솔'로 재정의. IDC 전망처럼 폴더블이 스마트폰 시장 유일한 성장 카테고리(CAGR 17%)가 되는 국면. 2031년 $110B 시장(모도르 인텔리전스) 실현 궤도.

### Worst Case (~20%): "애플워치 에디션의 재래"

$1,999 가격 + 무게 + Touch ID 후퇴가 발목을 잡고 초기 화제가 수요로 이어지지 않음. 경기 침체(스마트폰 시장 -14%) 속 1,800달러짜리 '두 번째 디바이스'는 우선순위에서 밀린다. 폴더블은 여전히 1.6% 니치로 남고 2세대 연기. 다만 애플 특성상 카테고리를 3~4년 끌고 가므로 완전 철수는 낮은 확률.

**핵심 판정**: Best든 Worst든 **2026년 4분기~2027년 1분기에는 물리적으로 설치 기반(700만 대 이상)이 생긴다.** 개발자 입장에서는 시나리오보다 이 타이밍이 더 중요하다.

## 4. 심층: 개발자·인디 게임에게 듀오는 무엇인가

### 4.1 iPad의 교훈 — '황금기'는 출시 후 6~12개월

2010년 아이패드 출시 때 최대 수혜자는 조급한 선점자가 아니라, 설치 기반이 잡힌 2010년 말~2011년에 최적화 앱을 내놓은 개발자들이었다(예: Paper, Notability, 잡지형 앱들). 폴더블 캔버스가 있는 듀오도 같은 곡선을 따를 확률이 높다. 10월 23일 출시 → 연말 성수기 설치 → 2027년 상반기에 '듀오 특화' 앱의 검색 수요 폭증. 지금 준비하면 정확히 그 물결을 탄다.

### 4.2 게임: 테이블탑 포스처 = 휴대용 콘솔

듀오의 가장 흥미로운 게이밍 잠재력은 90도로 세운 **테이블탑 자세**다. 상단 반쪽은 게임 화면, 하단 반쪽은 컨트롤러 — 안드로이드 17이 '폴더블 게임 모드'로 이미 검증 중인 바로 그 UX를, 애플은 `foldState`+`angleDegrees` API로 개발자에게 직접 열어준다. 갤럭시 폴드에서 증명된 시나리오(클래시오브클랜의 폴딩 연속성, 대화면 몰입형 게임)에 iOS 특유의 프레임워크가 더해지면:

- **보드게임·카드게임**: 펼친 화면에서 2인 대면 플레이(각 플레이어가 한쪽 화면 사용)
- **테이블탑 모드 게임**: 화면+컨트롤 분리로 하단 조작부 UI에 물리적 콘솔 감각
- **멀티태스킹 게임**: 게임 진행 중 위젯/전략 가이드 병렬 표시
- **Godot/HTML5 크로스플랫폼 자산**: 마스터의 HTML5·Godot 게임 자산은 화면 비율만 √2 대응하면 듀오에서 즉시 대화면 수혜

인디 개발자에게 이건 "새 플랫폼 포팅"이 아니라 "기존 자산의 레이아웃 재배치" 수준의 진입 장벽이다.

### 4.3 위험 요소 (Red Team)

🔴 **Anti-rationalization 체크: Authority Bias/Recency Illusion 해당 — 커뮤니티 API 문서는 예측 포함, 발표 직후라 낙관 보도 편중. 공식 문서 확정 전까지 foldState 명세는 '방향성'으로만 인용한다.**

- **초기 설치 기반은 작다**: 700~800만 대는 전체 아이폰의 ~3%. 듀오 특화에 올인하면 ROI가 안 나온다. 전략은 '적응형 레이아웃 공유 자산'이어야 한다.
- **√2 비율의 함정**: 비율 보존은 '스케일'을 보존할 뿐 '정보 밀도'를 보존하지 않는다. 펼친 화면에는 더 많은 콘텐츠를 보여줘야 하고, 이는 결국 모든 화면 크기에 대응하는 동적 레이아웃 작업으로 귀결된다(HN 논쟁의 결론이기도 하다).
- **Touch ID 단일 인증**: Face ID 없는 기기에서 카메라·AR·결제 흐름 설계가 달라진다. 앱의 인증 UX가 Face ID 전제라면 듀오에서 별도 대응 필요.
- **심사 정책 불확실성**: UIRequiresFullscreen 리젝 경고가 사실화되면 기존 앱의 긴급 업데이트가 필요할 수 있다.

## 5. Master에게 미치는 영향 & 액션 아이템

Master는 현직 iOS 개발자 + 인디 게임(HTML5/Godot) 사업자다. 듀오는 두 정체 모두에 직격하는 사건이다.

**단기 (지금~10월 출시 전)**
1. 보유 앱의 `UIRequiresFullscreen`·고정 frame 하드코딩 점검 — 레터박싱/리젝 리스크 선제 제거
2. SwiftUI 레이아웃을 사이즈 클래스 의존에서 **지오메트리/인텐트 기반**으로 마이그레이션하는 리팩터 목록 작성
3. Xcode 26/27 듀오 시뮬레이터에서 주력 앱 레이아웃 스크린샷 베이스라인 확보
4. 카메라 앱에 '듀오 프리뷰' 패턴 검토 — 뒷면 카메라로 자기 촬영 + 외부 화면 미리보기는 셀카보다 나은 UX라는 걸 애플이 시스템으로 증명함

**중기 (출시 후 6개월)**
5. 테이블탑 포스처 게임 프로토타입 1개 — Godot 기존 자산으로 foldState 대응 데모 (상단 게임/하단 UI 분할)
6. 듀오 최적화 업데이트를 마케팅 훅으로: "iPhone Duo ready" 배지는 App Store 검색·피처링에서 초기 가시성 이점이 될 수 있음
7. 위젯 세로 Today View가 열린 화면 좌측 상주 — 게임 일일 보너스 위젯 등 리텐션 접점 설계

**장기 (2027~)**
8. 2세대 가격 인하(베이스 시나리오 $1,499급) 시점에 듀오 특화 앱 1개 정식 출시 — 황금기 타이밍
9. 폼팩터 다각화(아이폰·듀오·아이패드·비전 프로)를 전제로 한 **단일 코드베이스 멀티캔버스 전략** — Godot/HTML5 자산의 √2 대응은 어차피 다른 플랫폼에서도 재활용되는 자산

## 미스 김 인사이트 — 이 리서치의 관전 포인트

1. **진짜 뉴스는 비율이다**: 듀오의 √2 종효비는 '화면이 커진다'가 아니라 '앱이 폼팩터를 넘나든다'는 소프트웨어 선언이다. 개발자 경쟁은 이제 화면 크기가 아니라 상태 전환 설계에서 벌어진다.
2. **폴더블의 7년 실패 원인 중 애플이 남긴 것은 가격뿐이다**: 주름·앱 생태는 시스템으로 해결했지만 $1,999는 유지했다. 즉 듀오 1세대는 '대중화'가 아니라 '프리미엄 표준 정립'이 목표다.
