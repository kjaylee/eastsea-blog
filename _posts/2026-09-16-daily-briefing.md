**1. Google, Gemini 3.8 Live·3.8 Live Extended Thinking 공개 — 실시간 음성 추론 전쟁 개막**
- **사실:** Google이 9월 15일 대화형 음성 모델 두 종을 발표했다. 3.8 Live는 규모·비용 효율형, 3.8 Live Extended Thinking은 복잡 과제용 다단계 추론형이다. 대화 도중 **97개 언어를 자동 감지·전환**하고, 도구·API 호출을 백그라운드로 실행한 채 대화를 이어간다.
- **수치:** Artificial Analysis 스피치투스피치 품질지수 **1위(82.6점)**, τ-Voice 에이전트 과제완료 **68.6%**, τ-Voice-banking **35.1%**, Big Bench Audio **97.7%**. LiveKit·Vercel·LangChain 등 주요 플랫폼이 Live API 통합을 제공한다.
- **시사점:** 텍스트 LLM 경쟁이 포화된 만큼 전선이 '전화·현장 업무용 음성 에이전트'로 이동 중이다. 게임 내 음성 NPC, 고객 지원 자동화, 헬스케어 콜센터가 첫 수혜 후보. 음성 UX를 노리는 인디 빌더는 Live API 진입장벽이 크게 낮아졌다.
→ 원문: [Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/)
→ 교차확인: [HN 토론 (144 points)](https://news.ycombinator.com/item?id=49715947)

**2. TypeSafe AI 'Jev' — 문자열을 버린 프론티어 모델, "환각 불가능" 설계**
- **사실:** 전 OpenAI 연구자 Diogo Almeida가 2년의 스텔스 끝에 'System One 모델'이라는 새 부류를 공개했다. Jev는 자유 문자열 생성을 포기하고, 입력된 비정형 상태에 대해 **타입 안전한 구조화 판단 + 보정된 확률**만 출력한다. 학습법은 RLCD(Reinforcement Learning for Calibrated Decisions), 샘플링은 병렬이다.
- **수치:** 입력 **$0.042/MTok**(출력 무료), 엔드투엔드 응답 **70~500ms** — 동급 지능 대비 **40~200배 빠르고 40~400배 저렴**하다고 주장한다. HN에서 화요일 최상위(212 points) 논쟁 중이다.
- **시사점:** "LLM을 if문 안에 넣는" 소프트웨어 내장 지능이라는 접근은 자동화 파이프라인의 병목(파싱·지연·과신)을 정면으로 공략한다. 극단적 주장이라 검증 시간이 필요하지만, 에이전트 오케스트레이션 비용 구조를 바꿀 잠재력이 있다.
→ 원문: [Introducing System One Models and Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)
→ 교차확인: [HN 토론 (212 points)](https://news.ycombinator.com/item?id=49717558)

- **사실:** Internet Archive가 9월 15일 공식 블로그에서 Wayback Machine에 고볼륨 자동화 트래픽이 밀려들어 보호 장치를 가동 중이라고 밝혔다. HTTP 429(요청 과다) 차단이 일반 이용자를 오타로 잡는 경우가 있어, 차단 메시지를 다시 쓰고 악성 봇과 사람을 구분하는 정밀도를 높이는 중이다.
- **수치:** HN **201 points** — 아카이브 접근성 문제로 개발자 커뮤니티의 공감을 얻었다. 오류 차단 피해자는 OS·브라우저·IP와 함께 info@archive.org로 제보하면 된다.
- **시사점:** 공공 아카이브가 AI 크롤링 시대의 비용을 직접 떠안는 구조가 됐다. 인용 링크 검증·역사 데이터 파이프라인이 Archive 의존적이라면 429 재시도 백오프와 미러 전략을 점검해야 한다.
→ 원문: [An Update on Wayback Machine Access](https://blog.archive.org/2026/09/15/an-update-on-wayback-machine-access/)
→ 교차확인: [HN 토론 (201 points)](https://news.ycombinator.com/item?id=49716176)
