## 🔬 AI/인공지능

**1. Claude Opus 5.5 출시 — "Fable 5.1급 성능, Opus 5보다 40% 저렴"**
- **사실:** Anthropic이 9월 22일 Claude 5.5 시리즈 첫 모델 Opus 5.5를 공개했다. 출시 전 METR 등 외부 평가기관의 사전 테스트를 거쳤고, 자체 행동 감사(behavioral audit)에서 "역대 최고 점수"를 기록했다.
- **수치:** 입력/출력 토큰당 **$4/$20**(Opus 5 대비 20% 인하), 캐시 읽기 **$0.20**(-60%), 일반 워크로드 기준 **40% 저렴**, 출력 속도 **30% 이상 빠름**. 에이전틱 코딩 Terminal-Bench 4.0 **66.4%**(GPT-6 Astra 57.9% 대비 우위). 얼리 테스터는 **68만 줄 코드 마이그레이션을 하루 만에** 완료했다.
- **시사점:** 프런티어 모델의 가격·속도 동시 개선은 API 비용 기반 서비스·에이전트 파이프라인의 마진을 직접 개선한다. Sonnet 5.5·Haiku 5.5가 몇 주 내 추가될 예정이라 하반기 크로스모델 벤치마크 재편이 예고된 상태.
→ 원문: [Introducing Claude Opus 5.5 (Anthropic)](https://www.anthropic.com/claude-opus-5-5)
→ 교차확인: [Claude Opus 5.5 — API Pricing & Benchmarks (OpenRouter)](https://openrouter.ai/anthropic/claude-opus-5.5)

**2. 서드파티 검증 — "코딩 실무에서 격차 확인"**
- **사실:** Sonar와 CodeRabbit이 Opus 5.5 출시 직후 독립 평가를 발표했다. 두 업체 모두 코딩 정확도·보안 취약점 탐지·리뷰 품질에서 Opus 5 대비 유의미한 향상을 확인했다.
- **수치:** Sonar 평가에서 코딩 정확도·복잡도·버그·보안·유지보수성 지표가 전반 개선됐고, CodeRabbit은 코드리뷰 벤치마크에서 입력가 **20%·출력가 20% 인하**와 성능 향상이 동시에 일어났다고 분석했다.
- **시사점:** 자체 벤치마크만이 아니라 정적분석·리뷰 자동화 업체의 실무 데이터도 같은 방향이라는 점이 중요하다. 코드 품질 게이트 자동화 스택의 기본 모델 재선택 시점이다.
→ 원문: [Claude Opus 5.5 평가 (Sonar)](https://www.sonarsource.com/blog/claude-opus-5-5-an-evaluation)
→ 교차확인: [Claude Opus 5.5 Code Review Benchmarks (CodeRabbit)](https://www.coderabbit.ai/blog/opus-5-5-model-review)

**3. Anthropic, IPO 직전 신모델 카드 검토 — GPT-6 Astra 견제**
- **사실:** Reuters가 소스 3곳을 인용해 Anthropic이 OpenAI의 GPT-6 Astra 출시 이후 모멘텀을 따라잡기 위해 IPO에 앞서 추가 신모델 공개를 검토 중이라고 9월 19일 보도했다.
- **근거:** Opus 5.5의 조기 출시(9/22)는 이 보도 이틀 뒤 실제로 이뤄졌고, 회사는 Sonnet 5.5·Haiku 5.5의 추가 출시도 예고한 상태다.
- **시사점:** 상장 전 성능 리더십 입증이 곧 밸류에이션 방어 수단이 된 첫 사례다. 모델 릴리스 일정이 자본시장 일정과 묶이는 구조가 향후 프런티어 랩의 표준이 될 수 있다.
→ 원문: [Anthropic considers releasing new AI model ahead of IPO (Reuters)](https://www.reuters.com/business/anthropic-considers-releasing-new-ai-model-ahead-ipo-sources-say-2026-09-19)

- **수치:** 주간 **+11,262스타**(총 21,594스타, 포크 1,247)로 2위와 큰 격차.
- **시사점:** '에이전트 스킬'이 독립 배포 단위로 정착하며 기업 인프라 업체가 스킬 마켓을 선점하려는 움직임이다. 보안 점검을 에이전트 파이프라인에 내장하는 게 이제 커뮤니티 주류 요구사항.

**8. alibaba/open-code-review — LLM 하이브리드 코드리뷰, 주간 +6.9k**

- **시사점:** 리뷰 자동화가 'LLM만 쓰는 방식'에서 '정적 분석 + LLM' 하이브리드로 수렴하는 신호다. 자체 리뷰 게이트를 만들 때 참고할 만한 아키텍처.
