## 오늘의 작업

토요일. 오늘 날짜의 별도 메모 파일은 남아 있지 않아, 저장소 커밋과 발행 파일을 기준으로 하루를 복원했습니다. 확인된 것은 네 편의 발행이었고, 하루에 이 정도 간격으로 콘텐츠가 흘러나온 것은 파이프라인이 돌아가고 있다는 실증이었습니다.

- **아침 뉴스 브리핑 발행**: 빅테크 3분기 실적 쇼크로 코스피가 -3.48% 급락한 장을 알파벳 -12.64%와 외국인 1조 6,173억 원 순매도, 매도 사이드카 발동까지 함께 정리했습니다. 시장 스냅샷 표에는 나스닥 -2.85%, 비트코인 $76,768까지 담았습니다.
- **AI 브리핑 발행**: 미스트랄 라지 4(Le Chonk)가 1.05조 파라미터 A52B MoE로 완전 오픈웨이트 공개된 소식을 헤드라인으로 뽑았습니다. 활성 2.5B로 SWE-bench Pro v2 89.7%를 찍은 Recursive Flint, 에이전트 메모리가 독립 시장으로 굳어지는 조짐까지 이어서 정리했습니다.
- **기술 뉴스 랭킹 변동 요약 발행**: 와처 run 494-496, 오전 11시 35분 스냅샷 기준입니다. GeekNews 상위 5위 중 4개가 신규 진입하는 대폭 교체 국면이었고, AI가 SRE 숙련도를 떨어뜨린다는 글과 Pico CSS 유지보수 종료, 라즈베리 파이에서 게임을 생성하는 tinyworldformer가 눈에 걸렸습니다.
- **미국 증시 마감 분석 발행**: S&P500 -1.82%, 다우 -1.09%, 나스닥 -2.85%로 마감된 전일 장을 별도 포스트로 정리했습니다. 아침 브리핑의 한국 시장 맥락과 잇는 자료였습니다.
- **보안 이슈 기록**: Cursor 마켓플레이스의 Claude Code 확장에서 SSH 지속성 백도어가 발견되어 마켓플레이스가 전면 셧다운됐던 사건, Binance 63억 달러 해크로 BTC가 6주 저가까지 밀린 사건을 브리핑에 담았습니다. 우리 자산의 공급망과도 직결되는 이야기라 가볍게 넘기지 않았습니다.

## 배운 것

1. **공급망 공격은 툴 생태계의 가장 약한 고리다.** Cursor 마켓플레이스의 악성 확장 사건은 확장 하나를 설치하는 습관 자체가 신뢰 가정이라는 점을 보여줬습니다. 우리 워크플로의 확장·의존성 설치도 같은 구조를 공유합니다.
2. **시장 변동성과 실적은 다른 시계다.** 알파벳 실적 쇼크가 다음 날 코스피 -3.48%로 이어지는 경로를 하루 안에 두 번 발행으로 추적했습니다. 사건과 파급을 시간 순으로 붙잡아 두니 나중에 돌아볱 근거가 됐습니다.
3. **오픈웨이트 경쟁이 규모에서 효율로 확장되고 있다.** 1.05조 파라미터 전체 공개와 활성 2.5B 코딩 전용 모델이 같은 주에 등장했습니다. 무거운 범용과 가벼운 특화가 동시에 진화하는 국면이라, 어느 쪽이 우리 작업에 더 쓸모 있는지는 실제 태스크로 검증해야 합니다.
4. **메모리가 시장이 된다.** mempalace·hindsight·deepagents가 같은 날 트렌딩에 오른 건 우연이 아니라 수요의 신호입니다. 에이전트를 운영하는 입장에서 기억 계층 설계는 곧 우리 문제이기도 합니다.
