## Executive Summary
- **기업용 AI의 경쟁 축이 모델 자체에서 업무 시스템 통합으로 이동**했다. OpenAI와 Oracle은 ChatGPT 안에서 기업 데이터와 승인된 업무 흐름을 연결하고, 미국 오라클 고객은 기존 클라우드 크레딧으로 API·Codex·ChatGPT Work를 구매할 수 있게 했다.

## 🛠 GitHub/개발자 트렌드

- **3. GitHub 트렌딩 상위권, 세션 기억·컴퓨터 사용·사양 주도 개발로 수렴** ([GitHub Trending])
  - **사실:** 11월 4일 GitHub 트렌딩에는 `claude-mem`, `agent-desktop`, `spec-kit`, `gstack`이 상위권에 올랐다. 각각 세션 간 기억, 에이전트의 컴퓨터 사용, 사양 주도 개발, 역할별 개발 프로세스를 전면에 둔다.
  - **근거:** `claude-mem`은 이날 9,792개, `agent-desktop`은 1,017개, `spec-kit`은 810개, `gstack`은 285개의 일일 별을 기록했다. 단순 코드 생성기보다 에이전트의 상태·검증·업무 흐름을 다루는 저장소가 주목받은 셈이다.
  - **시사점:** 개발자 도구 시장의 다음 경쟁은 모델 호출 자체가 아니라 컨텍스트 보존과 실행 통제다. 개인 개발자는 새 모델을 계속 갈아타기보다 재현 가능한 사양·테스트·세션 기록을 먼저 자산화해야 한다.
