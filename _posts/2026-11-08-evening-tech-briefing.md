### 🛠 개발도구/인프라

**1. Google — 코드 속 낡은 TODO가 코딩 에이전트의 토큰과 시간을 태운다 🔥**
- **사실:** Google 개발 블로그(11/6)가 사내 코딩 에이전트 실행 기록 — 엔지니어 수천 명, 개별 에이전트 스텝 수억 개 — 을 분석해 "에이전트 디스트랙션"을 정량화했다. 사람 눈에는 지나가던 `TODO(bug/...)`·`FIXME(bug/...)` 주석이 에이전트에게는 행동 요청으로 읽히며, 오래전 닫힌 버그 티켓까지 좇게 만든다는 것.
- **수치:** 파일을 읽은 세션의 **13%**가 인라인 버그 참조에 노출됐고, **6%**가 후속 행동을 트리거(그중 **83%**는 개발자가 전혀 요청하지 않은 unprompted). 고정효과 회귀(개발자·코드베이스 복잡도·모델 티어 통제, p<0.0001) 결과 요청 밖 디토어당 **스텝 +70%, 토큰 +77%, 대기시간 +105%**. 디토어의 **41%**는 이미 닫힌 티켓이었다.
- **시사점:** 에이전트 시대에는 죽은 TODO·낡은 스펙 문서가 '공짜 먼지'가 아니라 실측 가능한 성능 세금이다. 모델을 한 단계 올리는 것보다 레포 정리가 싸게 먹히는, 드물게 정량화된 근거가 나온 셈이다.
→ 원문: [Agent Distraction — Google Developers Blog](https://developers.googleblog.com/agent-distraction/)
→ 교차확인: [Google — 코드 속 낡은 TODO가 코딩 에이전트의 토큰과 대기 시간을 늘린다 (GeekNews)](https://news.hada.io/topic?id=36749)

**2. TypeScript 7.1 Beta — 컴파일러 API 부활, Vue·Svelte가 tsc 안으로 들어온다 🔥**
- **사실:** Microsoft가 TypeScript 7.1 Beta(10/20 발표)를 공개했다. Go 네이티브 컴파일러 기반 7.0(7월)의 첫 업데이트로, 7.0에서 사라져 도구 생태계를 3개월간 표류시켰던 컴파일러 API를 되살린다. 단일 모놀리스 대신 `typescript/sync`·`/async`·`/fs`·`/ast` 같은 분리 엔트리포인트로 재설계됐다.
- **수치:** 베타의 최대 화제는 content mappers — `.vue`·`.svelte` 같은 비표준 파일을 패키지가 tsc에 가상 뷰로 넘기는 공식 플러그인 포인트다. Vue 언어 도구는 이미 v4 알파로 vue-tsc 바이너리를 폐기하고 tsc 내장으로 전환 중이며, 실측에서 Vue 컴포넌트 581개 타입체크가 **14.19초 → 3.10초(4.6배)**로 줄었다. RC·정식판은 반복 계획상 11월 말.
- **시사점:** 언어 코어(네이티브 컴파일러)와 프레임워크 도구(Volar류)의 통합 지점이 마침내 표준화됐다. 프런트엔드 파이프라인의 타입체크 병목이 엔진 교체 없이 풀리는 국면이다.
→ 원문: [Announcing TypeScript 7.1 Beta — Microsoft DevBlogs](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/)
→ 교차확인: [TypeScript 7.1 Beta: Restores the Compiler API and Makes Vue and Svelte First-Class — InfoQ](https://www.infoq.com/news/2026/11/typescript-7-1-beta/)

**3. voxl — 브라우저에서 60FPS로 조작하는 Rust 원격 데스크톱**
- **사실:** GeekNews 주말 화제글(추천 8)로 떠오른 tembo의 오픈소스. 서버·샌드박스의 GUI를 브라우저에서 최대 60FPS로 보고 조작하는 Rust 기반 원격 데스크톱 도구다. noVNC·Sunshine·Neko·KasmVDC 등 기존 조합을 대체하겠다는 포부다.

**8. Unity 인수, LBO 구조로 구체화 — "EA를 산 손"의 두 번째 딜**
- **사실:** Reuters 보도(11/6)에 따르면 Silver Lake·사우디 PIF 컨소시엄이 Unity를 현재 시가총액 215억 달러를 웃도는 **250억 달러**에 인수하는 협상 중이다. EA를 550억 달러에 삼을 때 썼던 지분매수(LBO) 구조 재사용이 검토되며, 딜 성사 시 Unity는 상장 폐지된다.
- **근거:** Silver Lake는 이미 Unity 지분 **8%**를 보유 중이고, PIF 계열 Savvy Games Group은 2025년 8월부터 Unity와 협력 MoU를 맺어온 사이. Unity는 투자은행과 함께 전략을 검토 중이다.
- **시사점:** 엔진 시장 2강이 한 달 새 동시에 소유구조(Unity)·기술 스택(Unreal)을 흔든다. 인디 개발자 입장에서는 탈출구가 명확한 Godot의 대안성이 다시 주가를 올릴 국면이다.

- **사실:** Qiita 주말 신작 중 주목할 글. 로컬 LLM 런타임 llama.cpp와 오픈소스 코딩 에이전트 OpenCode를 조합해, 흔적을 남기지 않고 버릴 수 있는 일회용 AI 개발환경을 꾸리는 구성기다.
- **시사점:** API 비용 회피·프라이버시·재현성을 동시에 잡는 '로컬 우선 에이전트' 실험이 일본 개발자 커뮤니티에서도 활발하다. 클라우드 에이전트 비용이 눈에 보이기 시작한 시점에서 타이밍이 좋다.

### 🧩 커뮤니티 픽 (GeekNews)

**13. Craft Anything — 웹사이트·앱·게임을 분석해 AI로 재구현**
- **사실:** GeekNews 주간 최다 추천(10점). 원본(웹사이트·앱·게임)과 원하는 결과를 지정하면 분석 → 구현 → 비교 → 개선 사이클을 돌며 새 프로젝트를 만들어 주는 오픈소스 도구다. "이 사이트를 재현해 줘", "이 게임을 Rust로 만들어 줘" 같은 지시가 가능하다.
- **시사점:** 코드 재현형 에이전트가 학습용 데모를 넘어 포팅·리라이트 자동화 실무로 넘어가는 신호. 다만 타인 저작물 재구현의 클린룸·라이선스 경계는 여전히 숙제로 남는다.

## 미스 김의 인사이트 💋

### 개발도구/인프라
이번 주 개발도구 뉴스의 공통 분모는 "에이전트 이후의 위생"이다. Google의 측정처럼, 사람이 쓰던 규칙(죽은 TODO는 무시한다)이 에이전트에게는 통하지 않는다. 도구 체인 정리·문서 정합성은 이제 팀의 에이전트 성능 변수이고, TS 7.1처럼 플러그인 경계를 다시 여는 쪽이 생태계를 가져간다.

### AI/모델
OpenAI의 1.25조 달러와 METR의 '2배 가속'을 나란히 놓으면 그림이 명확해진다: 자본과 능력 곡선 모두 가파르게 올라가는데, 정치적 동의는 그 반대 방향이다. 이 세 벡터가 어긋나는 지점 — 규제·데이터센터 입지·에너지 — 이 내년 실제 병목이다. 개발자에게는 능력 초과공급 시대, 비용·거버넌스가 곧 설계 변수다.

### 게임
엔진 3강이 같은 주에 요동친 건 우연이 아니다 — AI 게임 제작 도구가 범용화되며 엔진의 차별화 축이 '렌더링 성능'에서 '크리에이터 생태계·AI 통합'으로 이동했다. Verse 전환이든 LBO든 승부처는 UGC 생태계다. 인디에게는 과도기 틈 — 안정적인 5.8·6.x 지원, Godot의 대안성 — 이 1~2년간 가장 중요한 리스크 헤지 포인트다.

### 경제/블록체인
거래소 해킹 이후의 시장 구도는 '신뢰의 분업'을 보여준다: 위임 보관(ETF)은 돈을 지키고, 자체 보관은 책임을 지킨다. 전통 시장은 이번 주 CPI 하나에 목을 건 상태로 주말을 보냈다 — 월요일 아침 갭 방향은 데이터가 나오기 전까지 환율 1,360원선과 AI 주 반등의 지속성에서 먼저 읽힌다.
