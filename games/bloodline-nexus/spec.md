## One-line Definition

혈통 카드(씨수마 × 모계) 2장을 교배해 Nicks 호환도·COI 인브리딩·잡종 강세를 읽고 3세대 금탁 교배를 완성해 최강의 명마를 만드는 육성/카드 합성 게임.

## Core Mechanic

1. **교배 선택** — 씨수마 8종(딥 임팩트·콘트레일·심볼리 루돌프·파워블레이드·제이에스홀드·노던 댄서·미스터 프로스펙터·씨애틀 슬루) × 모계 6종(골든파워·헤일 투 리즌 여계·네이티브 댄서 여계·로베르토 여계·선데이 사일런스 여계·제주 토종 계열). 선택 즉시 Nicks·COI·잡종 강세 미리보기.
2. **Nicks 호환도** — v3 §2 표 기반: GOOD(+8)/NEUTRAL(+2)/BAD(-4). nd×htr = GOOD(실제 G1 다수 사례), mp×htr = BAD(비호환 사례).
3. **COI 인브리딩 트레이드오프** — v3 §3 공식 `Σ(0.5)^(n1+n2+1)`으로 공통 조상 경로 합산. 수준별 보너스(+3/+7/+12)와 리스크(15%/30%/50% 롤 실패 시 -2/-5/-10 페널티 + 리스크 이벤트 텍스트). 고위험·고수익 구조를 원문 그대로 반영.
4. **잡종 강세** — v3 §4: 계통 상이 시 +3, 양쪽 평균 스탯 52+ 시 추가 +4(성공 조건 1 반영). 동계열은 강세 없음.
5. **3세대 금탁 교배** — G1 자마를 G2 씨수마로 승격(내 혈통 카드) 가능. G3 완성 시 최종 평가(성능 지수 + 균형 보너스 + 닉 시너지 + COI 고정 가치) → S/A/B/C 등급.
6. **부자 계승** — v8 1호 §3.1: 이전 플레이에서 스코어 200+ 명마를 완성하면 다음 플레이에서 `legacy=true`, G1 자마 전 스탯 +6. 명마 이름이 각인으로 타이틀·교배 화면에 노출(딥→콘트레일 모티프).

## Game Loop

타이틀(기록·각인·연구 원천) → 교배 선택(미리보기) → 교배 실행 → 자마 탄생(리스크 판정·이벤트) → G+1 (총 3세대) → 최종 결산(등급·기록 갱신) → 계승 또는 새 시작.

## Wow Factors

1. **실제 혈통학 메카닉 이식** — COI 공식·Nicks 테이블·잡종 강세를 그대로 게임 수치로 변환 (원문 구조 훼손 없음)
2. **고위험 고수익 인브리딩** — 밴드별 보너스 vs 리스크 롤. "극단적 특성 +50% 리스크"를 선택할지 사용자가 판단
3. **딥 임팩트→콘트레일 계승 서사** — 명마의 혈통이 세이브를 넘어 다음 플레이에 각인으로 남는 2세대 플레이 구조
4. **한국 경마 특화 카드 풀** — 파워블레이드·골든파워·제주 토종 계열로 한국 혈통 연구(korea/bloodlines.md) 직접 반영
