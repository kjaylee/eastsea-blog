## One-line Definition

12주 시즌, 성적 압박과 무작위 검사 사이에서 마방의 컨디션·재활·평판을 관리하며 "클린"을 지키는 카드형 마방 감독 시뮬레이션.

## Core Mechanic

- **주간 이벤트 덱**: 레이스 35% / 샘플 채취 25% / 구름 진단 15% / 언론·스폰서 15% / 조정 주 10% (시드 결정론).
- **레이스 주**: 출전 마필 선택 → 조치 3택(정상 조교 +10 / 조정 -5 / 회색 처방 +22·노출 +2) → 지수 대결(컨디션 + 난수) → 부상 판정(기본 6% + 과조교 10%p + 재발 이력×50%).
- **샘플 채취**: 노출(heat) 기반 적발 확률 `min(85%, 15%+노출×9%)`. 노출 0이면 절대 음성 + 평판 +4. 적발 시 마필 6주 정지·평판 -25·스트라이크 +1, 2스트라이크 = 8년 정지 배드 엔딩.
- **노출(heat) 경제**: 스테로이드 +2, 자연 감쇠 -0.5/주 — "한 번의 약이 세 주의 그림자".
- **클린 보너스**: 시즌 무투약 + 무적발 시 +300점 "클린 스튜어드" 엔딩. 승리 100점·평판×4와 경쟁하는 장기 유혹 저항 설계.
- 최고 기록(총점·평판·승수·클린 시즌 횟수) localStorage 저장.

## Game Loop

타이틀 → 주간 이벤트 카드(연구 근거 노트 동봉) → 마필 선택·조치 → 결과(판정·로그) → 12주 경과 → 엔딩 4종(클린/회색지대/스캔들/8년 정지) → 재시작.

## Wow Factors

1. **Doping Temptation Trade-off** — 단기 성적(스테로이드 +22) vs 검거 리스크(누적 노출)의 확률 경제가 실제 2013년 사건 구조를 그대로 닮았다.
2. **Asymmetric Punishment** — 음성은 평판 +4, 양성은 마필 6주 + 평판 -25. 불对称 보상이 클린 플레이를 전략적으로 만든다.
3. **Recurrence Debt** — 가속 재활의 빚(재발률 50%+)이 이후 부상 판정에 영구히 남는다.
4. **Verdict Flash** — 무작위 채취 카드 오픈 순간의 적/음성 플래시가 매 시즌 긴장을 만든다.
