## One-line Definition

5주 일정 경영 시뮬레이션. 일본형(봄 2연전+장기 공백 후 가을 결전)과 미국형(5주 압축 3연전) 중 하나를 골라 훈련·휴양·방목을 배분하고 트리플 크라운을 정복하는 경영/스케줄 관리 게임.

## Core Mechanic

1. **두 일정 모드 선택** — 일본형(경주 2회 + 방목 1회, 여름 방목 전 스탯 +9·피로 -22) vs 미국형(경주 3회 + 훈련 2회, 경주 피로 +18·회복 기회 부족). 리스크 구조가 정반대 — v6 §1.1 vs v8 §1.1 대비 구조.
2. **스탯 전환 요구** — 경주별 요구 스탯이 속도(2000m/2012m)→지구력(2400m/1900m)→스태미나(3000m)로 전환. 거리 계단 2000→2400→3000m(v8 §1.2) + 미국 더트 1900→2012→2400m(v6 §1)를 요구치로 반영.
3. **무패 클리어 업적** — 3연승 + 마진 합 ≥ 5로 달성. 승률 공식(0.45 + 0.045/s탯 초과) 기준 무패 달성률 ~3.5% 수준 튜닝 (v8 §3.2 수치 근거).
4. **라이벌 역전 이벤트** — 최종 관문에서 라이벌(일본: 라이스 샤워 / 미국: 알리다)이 패배 시 역전당하고 승리 시 마진 추격 이벤트 텍스트. 미호노 부런 좌절(v8 §4)·Affirmed–Alydar(v6 §3.5) 사례를 이벤트 서사로.
5. **부자 계승 보너스** — 3관 클리어 후 "계승 — 2세대 시작"을 선택하면 저장에 혈통이 기록되고 다음 플레이에서 전 스탯 +6. 딥 임팩트→콘트레일 패턴(v8 §3.1).

## Game Loop

타이틀(모드 선택·기록·연구 원천) → 5주 일정 진행(행동 주차: 훈련 3종/휴양, 방목 주차, 경주 주차: 결과+이벤트) → 결산(클리어/무패 업적) → 계승 또는 재도전.

## Wow Factors

1. **실제 일정 체계의 대비** — 일본 vs 미국 3관의 구조적 차이(거리 계단 vs 시간 압박)가 게임 메카닉 그 자체
2. **경영 판단의 연쇄** — 훈련(+12/피로+4) vs 휴양(피로-16)의 트레이드오프가 5주 간격에 걸쳐 누적
3. **~3.5% 희귀 업적** — 무패 3관의 역사적 희소성을 확률 곡선에 반영
4. **혈통 계승 서사** — 클리어한 말의 이름이 2세대 세이브에 남아 보너스를 물려줌 (콘트레일 모티프)
