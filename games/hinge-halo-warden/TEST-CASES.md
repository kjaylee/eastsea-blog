# Hinge Halo Warden — Test Cases

## Functional
- `TC-F001` 타이틀 화면에 게임명, 설명, 시작 버튼, 최고 기록이 보인다.
- `TC-F002` 시작 버튼 탭 시 플레이 화면으로 진입한다.
- `TC-F003` 셔터 손잡이 근처를 드래그 후 릴리스하면 셔터 스냅이 발동한다.
- `TC-F004` 셔터 스냅이 적을 맞히면 점수와 콤보가 상승한다.
- `TC-F005` 완벽 각도에서 적을 맞히면 `Perfect Hinge` 배너와 금색 잔광이 뜬다.
- `TC-F006` 웨이브 클리어 후 `Brace Draft` 3택이 열린다.
- `TC-F007` 업그레이드 선택 후 다음 웨이브 플레이가 가능하다.
- `TC-F008` `Pulse` 버튼 사용 시 에너지가 소모되고 중심 광역 타격이 일어난다.
- `TC-F009` 코어 내구도 0이 되면 결과 화면으로 전환된다.
- `TC-F010` 결과 화면에서 `Retry`로 새 런을 바로 시작할 수 있다.

## Wow Factors
- `TC-W001` 첫 10초 안에 셔터 선택 → 드래그 → 스냅 입력이 가능하다.
- `TC-W002` 30~90초 구간에 적 속도 또는 혼합 패턴이 유의미하게 상승한다.
- `TC-W003` `Brace Draft` 업그레이드 중 최소 1개가 이후 플레이에 반영된다.
- `TC-W004` `Perfect Hinge` 연출 시 화면 정지/배너/금색 잔광 중 2개 이상 보인다.
- `TC-W005` `Daily Oath`가 타이틀과 결과 화면에 모두 표시된다.

## UI / Mobile
- `TC-U001` 390x844 뷰포트에서 HUD, 버튼, 캔버스가 잘리지 않는다.
- `TC-U002` 가로 스크롤이 없다.
- `TC-U003` 주요 버튼의 터치 영역이 대략 44px 이상이다.
- `TC-U004` safe-area inset을 고려한 상단/하단 배치가 적용된다.

## Persistence
- `TC-S001` 최고 점수, 최고 웨이브, 플레이 횟수가 localStorage에 저장된다.
- `TC-S002` `Daily Oath` 최고 점수가 날짜 키 기준으로 저장된다.
- `TC-S003` 재로드 후 저장된 최고 기록이 타이틀에 다시 표시된다.

## Stability
- `TC-P001` 페이지 로드 후 JS pageerror가 0이다.
- `TC-P002` 캔버스가 실제로 렌더링되어 빈 화면이 아니다.
- `TC-P003` 결과/재시작까지 최소 1회 런이 완주된다.
- `TC-P004` 텍스트 `undefined`가 DOM에 나타나지 않는다.

## QA Execution Notes
- `?qa=1` 쿼리로 자동 스모크 모드를 실행한다.
- 자동 스모크는 시작, 핵심 방어, 업그레이드, 게임오버, 재시작, 저장을 한 번씩 통과해야 한다.
