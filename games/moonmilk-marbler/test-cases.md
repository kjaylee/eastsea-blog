| TC-F002 | 플레이 진입 | 시작 버튼 탭 | 모드 `play`, 작품 1, 타이머, 캔버스 통 표시 |

| TC-F004 | 실시간 판정 | 안료를 목표 안팎으로 이동 | 일치율이 포괄률과 정밀도에 따라 0~100 범위로 갱신 |
| TC-F005 | 인쇄 공개 | 타이머 만료 또는 큐에이 강제 인쇄 | 입력 동결, Stamp Reveal, 작품 점수와 스냅샷 표시 |
| TC-F006 | 공방 선택 | 첫 인쇄 후 기법 하나 선택 | 선택 화면 종료, 효과 누적, 다음 작품 시작 |
| TC-F007 | 에스컬레이션 | 작품 2·3 진행 | 이동/회전 목표, 역류 펄스 또는 추가 색상 적용 |
| TC-F008 | 게임 종료 | 세 번째 인쇄 완료 | 결과 화면, 합계, 등급, 최근 작품 표시 |
| TC-F009 | 재시작 | 결과의 다시 빚기 탭 | 새 실행의 작품 1로 진입 |
| TC-F010 | 타이틀 복귀 | 결과의 공방 탭 | 타이틀과 갱신된 저장 통계 표시 |
| TC-W001 | Moonmilk Vortex | 빠른 직선과 느린 원형 드래그 비교 | 힘 반경/접선 회전이 달라 서로 다른 흐름 생성 |
| TC-W002 | Rising Motif | 작품 1과 3의 상태 비교 | 작품 3의 목표/펄스/입자 구성이 더 복잡함 |
| TC-W003 | Atelier Technique | 서로 다른 기법 선택 | 반경·정밀도·금박 보너스 중 실제 상태 하나 이상 변화 |
| TC-W004 | Perfect Bloom | 90% 이상 결과 강제 | 슬로모션/금박/팔레트 반전 플래그와 축하 문구 표시 |
| TC-W005 | Daily Moonfolio | 한 판 종료 후 저장 조회 | 날짜 키, 일일 최고, 최근 작품 최대 6개 유지 |
| TC-I001 | 한국어 | 기본 로드 | 화면에 한국어 설명, `undefined`/`NaN` 없음 |
| TC-I002 | 영어 | 언어 버튼 탭 | 제목 외 안내·버튼·결과가 영어로 전환 |
| TC-U001 | 모바일 | 390×844 터치 뷰포트 | 가로 스크롤과 주요 UI 겹침 없음 |
| TC-U002 | 터치 좌표 | 캔버스 경계에서 드래그 | 기준 좌표로 제한되고 문서 스크롤 없음 |
| TC-U003 | 안전 영역 | 노치/홈 인셋 환경 | 상단 통계와 하단 안내가 safe-area 안에 위치 |
| TC-S001 | 저장/로드 | 종료 후 새로고침 | 최고점, 실행 수, 오늘 최고, 갤러리 복원 |
| TC-S002 | 저장 손상 | 잘못된 제이슨을 저장 후 로드 | 기본값으로 복구하고 페이지 오류 없음 |
| TC-P001 | 로드 성능 | 로컬 정적 서버에서 로드 | DOMContentLoaded 5초 이내 |
| TC-P002 | 자바스크립트 오류 | 전체 자동 큐에이 실행 | `pageerror` 0개, 관련 콘솔 오류 0개 |
| TC-P003 | 렌더링 | 플레이 중 캔버스 픽셀 검사 | 빈 화면이 아니고 안료·목표·통이 렌더링됨 |
| TC-P004 | 입자 상한 | 3작품 진행 | 입자 수 650 이하, 한 프레임 델타 32밀리초 이하 |
| TC-Q001 | 큐에이 API | `?qa=1` 로드 | `__GAME_QA__`와 5개 참 와우 플래그 노출 |
| TC-Q002 | 목록 제이슨 | `games-list.json` 파싱 | 유효 제이슨, slug 1회, 공개 주소 정확 |

## 출시 게이트

- 모든 자동 검증 통과 전 커밋/푸시 금지.
- 390×844 실브라우저에서 title → play → choice → result → retry를 한 경로로 검증한다.
- `git diff --check`, 인라인 자바스크립트 구문 검사, 목록 제이슨 파싱, 금지 문자열 검사를 모두 통과한다.
