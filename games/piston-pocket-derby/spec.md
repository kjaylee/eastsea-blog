# Piston Pocket Derby — 피스톤 포켓 더비

## Candidate Decision

- 선택일: 2026-07-16 (목요일 아케이드/레이싱 로테이션)
- 선정안: `piston-pocket-derby`
- 비교안: Treadstamp Rally, Shadowcart Switchback
- 선정 이유: 양쪽 바퀴를 두 엄지로 따로 압축하고 놓는 조작은 첫 10초 안에 차별점이 보이며, 2D 물리로 하루 안에 완결할 수 있고 착지 장면이 공유 카드로 바로 이어진다.
- 가장 가까운 기존작: `chalkline-vault-finals` (예상 중복 42%). 단일 도마 반동과 달리 독립 바퀴의 접지·피치·연속 지형 주행을 동시에 다룬다.

## One-line Definition

두 엄지로 좌우 스프링 바퀴를 각각 압축·해제해 점프 자세와 착지 접지를 만드는 장난감 공방 레이싱 아케이드.

## Core Mechanic

- 화면 왼쪽/오른쪽을 누르고 있는 동안 해당 바퀴의 피스톤을 최대 100%까지 압축한다.
- 한쪽만 놓으면 해당 바퀴 반발이 차체 피치를 바꾼다. 왼쪽 해제는 코를 위로, 오른쪽 해제는 코를 아래로 회전시킨다.
- 두 쪽을 140ms 안에 함께 놓으면 반발이 합쳐져 높은 수직 점프를 만든다.
- 키보드 `A/←`, `D/→`는 동일한 입력의 접근성 대체 수단이다.
- 착지각, 수직 속도, 노면 기울기로 Perfect / Held / Bent 착지를 판정한다.

## Supporting Systems

- 날짜 문자열로 시드한 고정 Daily Workshop 트랙
- 굴곡 노면, 톱니 경사, 이동식 프레스 게이트로 후반 난이도 상승
- 두 체크포인트에서 서스펜션/관성/접지 중 하나를 고르는 Pit Bench Draft
- 완주 시 비행각, 완벽 착지 수, 최고 높이를 도면선으로 표시하는 Blueprint Finish Freeze
- 일일 최고점, 최고 Perfect 연속 기록, 차고 메달, 플레이 횟수 저장

## Game Loop

타이틀 → 양손 압축/해제 주행 → 착지 판정 → 체크포인트 드래프트 → 강화된 후반 지형/프레스 → Blueprint Finish Freeze → 재도전 또는 타이틀.

## Wow Factors

1. **Twin-Piston Touch**
   - 왜 강한가: 두 엄지의 압력이 곧 두 바퀴의 에너지와 차체 회전이 되어 조작 결과가 즉시 보인다.
   - 실제 구현 표면: 독립 포인터 캡처, 좌우 압축 게이지, 개별 해제 토크, 140ms 동시 해제 점프, 키보드 대체 입력.
   - 리텐션/공유 효과: 같은 지형도 해제 순서에 따라 다른 공중 자세가 나와 숙련 재도전을 만든다.

2. **Camshaft Escalation**
   - 왜 강한가: 평탄한 튜토리얼 뒤 굴곡과 톱니 경사, 왕복 프레스가 겹쳐 해제 순서를 새로 요구한다.
   - 실제 구현 표면: 진행 거리에 따라 진폭·주파수가 증가하는 결정론적 지형과 3개의 이동식 프레스 게이트.
   - 리텐션/공유 효과: 완주 기록뿐 아니라 후반 위험 구간 통과 실력이 점수 차이를 만든다.

3. **Pit Bench Draft**
   - 왜 강한가: 체크포인트마다 `Soft Coil / Brass Flywheel / Grippy Tread` 중 한 부품을 골라 주행 성향이 달라진다.
   - 실제 구현 표면: 반발력, 회전 관성, 착지 허용각을 실제 물리·판정 수치에 반영하는 두 번의 선택 오버레이.
   - 리텐션/공유 효과: 부품 조합별 다른 빌드와 점수 경로가 생긴다.

4. **Blueprint Finish Freeze**
   - 왜 강한가: 완벽 착지와 완주 순간을 청사진 도면 카드로 얼려 성과를 한눈에 읽게 한다.
   - 실제 구현 표면: 점수, 비행각, 최고 높이, Perfect 횟수, 부품 빌드를 도면선·치수선과 함께 표시하는 결과 화면.
   - 리텐션/공유 효과: 결과 화면 자체가 캡처 가능한 쇼오프 카드다.

5. **Daily Workshop Card**
   - 왜 강한가: 날짜별로 같은 트랙이 제공되어 같은 조건의 기록 경쟁이 가능하다.
   - 실제 구현 표면: 날짜 해시 시드, 오늘의 트랙 번호, 일일 최고점·Perfect 연속·차고 메달·플레이 횟수 localStorage 저장.
   - 리텐션/공유 효과: 매일 바뀌는 트랙과 메달 승급이 다음 방문 이유가 된다.
