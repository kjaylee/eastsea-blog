### 3. VS Code 1.130이 에이전트 세션 관리와 승인 흐름을 전면 다듬었습니다

**[VS Code 1.130이 에이전트 세션 관리와 승인 흐름을 전면 다듬었습니다]**

- **발표:** 7월 22일 공개된 VS Code 1.130은 에이전트 호스트를 전용 프로세스로 분리하고, Agents 창 검토 흐름과 도구 승인 경험을 개선했습니다.
- **핵심:** 같은 세션을 여러 VS Code 창에서 연결할 수 있는 **dedicated agent host**, 파일 통계와 compact diff를 붙인 리뷰 창, 모델이 도구 호출 위험을 평가하는 **assisted tool approvals**가 핵심 변화입니다. 즉 "채팅 잘 되나"보다 "에이전트 세션을 어떻게 운영·검토·승인하나"가 제품 포인트가 됐습니다.
- **시사점:** IDE 경쟁은 이제 자동완성 품질만으로 설명되지 않습니다. 팀이 실제로 돈을 내는 지점은 장시간 세션 안정성, 멀티파일 리뷰 속도, 승인 피로도 감소 같은 운영 ergonomics입니다.

→ 원문: [Visual Studio Code 1.130](https://code.visualstudio.com/updates/v1_130)
