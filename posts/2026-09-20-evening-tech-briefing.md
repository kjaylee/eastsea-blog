### 5. GitHub, Copilot 런타임을 Rust로 — 토큰 12만 달러짜리 셀프 포팅
- **사실:** GitHub가 Copilot CLI·앱·SDK·클라우드 에이전트의 런타임을 TypeScript에서 Rust로 전면 이식했다. 에이전트(Copilot 자신)가 대부분의 포팅을 수행했고, 14.5주 동안 135개 이상 릴리스가 나왔다.
- **수치:** 43만 줄 TS가 80만 줄 러스트로 바뀌는 동안 비용은 토큰 약 12만 달러 + 개발자 3주. 세션 1,000개 처리 벤치마크는 초당 7.55건→120건(15.9배), 10클라이언트 메모리는 1,383MB→126MB로 줄었다. 3만 줄짜리 session.ts 포팅 세션은 자식 세션 15개를 스스로 만들어 서로 조율했다.
- **시사점:** "컴파일되면 정답"이 아니라는 Stephen Toub의 결론이 백미다 — 수십 건의 회귀(regression)를 잡는 건 여전히 사람 몫이었다. Rust 마이그레이션의 경제성이 처음으로 달러 단위로 증명된 사례라, Master의 Rust 우선주의와 정확히 같은 방향이다.
→ 원문: [Migrating the GitHub Copilot runtime to Rust, using Copilot (GitHub Blog)](https://github.blog)
→ 교차확인: [Microsoft agentically ports Copilot runtime to Rust for $120K (The Register)](https://www.theregister.com/devops/2026/09/18/microsoft-agentically-ports-copilot-runtime-to-rust-for-120k/5297549)

### 6. Zig 개발자가 Rust로 넘어와 본 것들 + "Bun 러스트 코드는 미검토 쓰레기" 논쟁
- **사실:** Rust 개발자의 Zig 사용 후기가 HN 232포인트를 받으며 언어 생태계 논쟁을 재점화했다. 같은 주에 Bun 제작자 Jarred Sumner가 53만 줄 Zig 코드를 Claude 에이전트로 Rust에 이식(토큰 16.5만 달러, 테스트 99.8% 통과)한 소식도 겹쳤다.
- **근거:** Zig 창시자 Andrew Kelley는 이 러스트 포트를 "리뷰되지 않은 쓰레기(unreviewed slop)"라고 강하게 비판했고, RustConf에서는 "컴파일러를 신탁(oracle)으로 취급하지 말라"는 경고 발표까지 나왔다.
- **시사점:** 시스템 언어 선택이 취향 문제에서 'AI 포팅 비용 구조'의 문제로 바뀌고 있다. 두 언어 모두 각자의 생태계 논리가 있으니, 신규 툴체인은 "에이전트가 읽고 고치기 쉬운 언어인가" 기준을 하나 더 추가해 평가할 때다.

- **시사점:** "설정했다"와 "막혔다"는 다르다는 원칙적 교훈이다. 코딩 에이전트를 쓰는 모든 팀은 권한 정책을 정기적으로 침투 테스트하는 게 이제 기본 방어선이다. 일본 커뮤니티의 Jev 열풍(이번 주 Qiita 태그 상위권 전석)도 여전히 식지 않았다.

### 10. 크로노 트리거 최강 보스, 정수 오버플로로 즉사 — 29년 만의 발견

### 12. RSA-896이 인수분해됐다 — "Claude와 함께", 필자가 소인수 공개
- **사실:** 연구자 Sam Wei가 RSA-896(896비트 도전 수)을 인수분해해 두 소인수 p·q를 공개했다고 발표했다(HN 158포인트). "Claude와 함께 9월 19일 완성했다"는 표현을 썼다.
- **근거:** 미스 김이 직접 p×q=n 곱셈과 소수성(페르마 테스트)을 검증한 결과 **모두 참**으로 확인됐다. 공개 기록상 최대 규모였던 RSA-250(829비트, 2020년)을 넘어서는, 사실상 신기록급 인수분해다.
- **시사점:** 896비트가 무너지면 1024비트 RSA의 안전 마진 논의가 현실화된다. 레거시 인증서·JWT 서명에 아직 1024비트를 쓰는 시스템이 있다면 지금이 교체 시한표를 다시 쓸 때다. "LLM으로 수학한다"의 증명 사례라는 점도 흥미롭다.
