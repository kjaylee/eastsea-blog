**1. SpaceXAI, 코딩 특화 'Grok 4.7' 출시 — 가격 동결로 모델 경쟁 격화** ★핵심
- **사실**: 9월 21일(현지시각) Grok 4.7 공개. Grok 4.6보다 큰 새 베이스 모델에 수 시간짜리 고난도 과제 비중을 높인 장기 강화학습으로 훈련됐다. GitHub Copilot 전 플랜에 순차 탑재되며 컨텍스트는 최대 50만 토큰.
- **수치**: DeepSWE v1.1 **71.0%**로 GPT-5.6 솔(72.7%), 페이블 5.1(70.0%)과 1%p 안팎 차이. 가격은 100만 토큰당 입력 **$2**·출력 **$6**로 전작과 동결.
- **시사점**: 프런티어 코딩 모델이 성능차 1%p, 가격 동결로 수렴 중 — API 비용에 민감한 인디 빌더의 에이전트 워크로드 단가가 구조적으로 내려가는 국면.

## 🛠️ GitHub/개발자 트렌드

**4. google/ax — Google의 에이전틱 오케스트레이션 런타임 오픈소스화, 하루 2,324스타** ★핵심
- **사실**: GitHub 트렌딩 1위. Google이 자사 에이전트 오케스트레이션 런타임 'ax'를 Go로 오픈소스 공개했다(누적 7,383스타, 공개 첫날 2,324스타).
- **근거**: rakyll(구글 엔지니어) 등이 빌드한 이 프로젝트는 에이전트 간 작업 분배·실행을 위한 공식 지원 런타임이라는 점에서 단순 개인 프로젝트와 결이 다르다.
- **시사점**: Go 진영에 에이전트 인프라 표준 후보가 등장 — Rust/Go 우선 원칙의 Master 스택과 궁합이 좋고, 에이전트 오케스트레이션 자체가 상품성 있는 도구 영역임을 재확인.
→ 원문: [google/ax - GitHub](https://github.com/google/ax)

**5. agent-substrate/substrate — 쿠버네티스 핵심 개발자들이 만드는 '에이전트 기반층'**
- **사실**: 하루 301스타. 쿠버네티스 API·컨트롤러 핵심 기여자들(thockin, BenTheElder 등)이 '에이전트를 위한 핵심 시스템(기반층)'을 Go로 구축 중이다(누적 2,887스타).
- **근거**: 만든 사람들의 이력이 곧 신뢰도 — 컨테이너 오케스트레이션을 만든 집단이 에이전트 오케스트레이션에 진입했다는 구도다.
- **시사점**: "에이전트 = 새로운 워크로드, 스케줄러가 곧 필요하다"는 판단이 k8s 원년 진영에서 나오는 것 — 인프라 레이어의 패러다임 전환 조기 신호로 기록할 만하다.
→ 원문: [agent-substrate/substrate - GitHub](https://github.com/agent-substrate/substrate)

**6. univer·treg — 'AI 오피스 하네스'와 '에이전트 도구용 OpenRouter' 동반 상승**
- **사실**: dream-num/univer(스프레드시트·문서·슬라이드·캔버스를 하나의 런타임에서 다루는 "AI 에이전트용 오피스 하네스", 누적 15,263스타)가 하루 202스타, superdesigndev/treg("에이전트 도구의 OpenRouter", 누적 2,134스타)가 하루 197스타로 트렌딩에 올랐다.
- **근거**: GitHub 트렌딩 페이지에서 두 프로젝트 모두 상위권 — 에이전트가 다룰 '대상(문서)'과 '도구(연결)' 양쪽 인터페이스가 동시에 성장 중이다.
- **시사점**: 에이전트 생태계가 모델 경쟁에서 '주변 인터페이스' 경쟁으로 확장 중 — 도구 라우팅·문서 조작 계열 신규 OSS 진입 포지션이 여전히 비어 있음을 의미.
→ 원문: [dream-num/univer - GitHub](https://github.com/dream-num/univer)
→ 교차확인: [superdesigndev/treg - GitHub](https://github.com/superdesigndev/treg)
