**1. GPT-6 솔, 과제당 $0.27 — '태스크 단위 단가' 시대 개막** ★핵심
- **사실**: OpenAI가 GPT-6 아스트라의 코딩·전문 업무·컴퓨터 사용 능력을 하위 모델로 내린 GPT-6 솔·루나를 공개하며 API 가격을 전 세대 대비 50% 인하했다(솔 입력 $2/출력 $10, 루나 $0.10/$0.50, 100만 토큰당).
- **수치**: 비즈니스 워크플로 벤치 AutomationBench에서 솔(xhigh)은 **33.2%·과제당 $0.27**로 클로드 오푸스 5(맥스, 26.9%)를 점수·비용 모두 압도 — 오푸스는 11.1배 비용. 페이블 5.1의 공식 비용은 오푸스 5 폴백(약 40% 과제 발생)을 빠져 실제로는 더 크다.
- **시사점**: 가격표 경쟁이 '모델 가격'에서 '완수 과제당 비용'으로 내려앉았다. 인디 빌더의 에이전트 상품 원가 구조를 이번 분기 안에 다시 계산해야 한다.

- **수치**: GitHub Actions에서 고성능 서드파티 러너로 이전해 잡 평균 **34% 단축**(tsc -52%), 네이티브 컴파일러 tsgo 전환으로 tsc 주간 중앙값 **-73%**, 타입 정보 의존 lint 규칙을 AST 정적 분석으로 재작성해 API lint **-68%** 후 Oxlint까지 이전.

**12. 사내 AI 37개 도구의 대화 이력 감사 — "지운다고 기록이 사라지지 않는다"**
- **사실**: Qiita 트렌드에 오른 글이 기업용 AI 도구 37개 제품의 대화 이력을 조사했다. 상사나 제공자가 언제까지 읽을 수 있는지, 삭제 후에도 몇 가지 경로로 기록이 남는지를 정리했다.
- **근거**: "채팅을 지웠다 ≠ 기록도 삭제됐다"며 백업·감사로그·모델 제공자 보관 등 5가지 잔존 경로를 짚은 점이 실무 독자의 공감을 얻었다.
- **시사점**: 기업 AI 도입의 다음 병목은 성능이 아니라 '대화 기록의 소유와 보존'이다. 개인 빌더도 고객 데이터를 에이전트에 흘리는 순간 같은 규율이 적용됨을 의미한다.
