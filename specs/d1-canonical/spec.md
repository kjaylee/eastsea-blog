# D1 단일 원장 전환 명세

## S1. 원장

- `posts` D1 테이블이 공개 서비스의 단일 원장이다.
- `posts.json`, 사이트맵, RSS/Atom은 D1에서 파생된 배포 산출물이다.
- 마크다운은 작성·감사·복구 자산이며 공개 목록 수의 기준이 아니다.

## S2. 홈페이지

- 하드코딩된 최대 게시물 수를 두지 않는다.
- API가 반환한 `total`개를 읽었거나 페이지가 비었을 때만 무한 스크롤을 종료한다.
- 카테고리 필터는 서버 쿼리로 전달해 빈 페이지 때문에 조기 종료하지 않는다.

## S3. 정적 투영

- D1의 모든 페이지를 중복 없이 수집한다.
- `posts.json`은 기존 소비자가 읽을 수 있는 `filename`, `date`, `category`, `title`, `excerpt` 형식을 유지한다.
- 사이트맵은 기존 비게시물 URL을 보존하고 D1 게시물 URL 전체를 교체한다.
- RSS 2.0, Atom 1.0, `feed.xml` 호환본은 최신 50건을 포함한다.
- XML과 JSON은 UTF-8로 생성한다.

## S4. 실패 안전성

- HTTP 오류, 선언 총계 불일치, 중복 slug, 빈 데이터, 비정상 응답은 실패다.
- 생성은 임시 파일에 완료한 후 대상 파일을 교체한다.
- 배포 스테이지 생성 중 투영 실패 시 Cloudflare Pages 배포를 시작하지 않는다.

## S5. 운영 및 복구

- 소스 트리의 기존 정적 파일은 호환성 기준본으로 남긴다.
- 실제 배포본은 매 배포 시 D1 최신 상태로 재생성한다.
- 기존 게시물·D1 행을 삭제하거나 다시 마이그레이션하지 않는다.
